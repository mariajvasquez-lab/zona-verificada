Medidas de seguridad

Cómo aprobamos personas en ambos lados.

01

Datos obligatorios

Trabajadores y buscadores registran nombre, teléfono, zona y correo para reducir perfiles anónimos.

02

Revisión de identidad

El trabajador sube DPI y foto de perfil. El equipo revisa manualmente antes de aprobarlo.

03

Perfil visible solo si está aprobado

Un trabajador pendiente, rechazado o sin suscripción activa no aparece públicamente.

04

Reseñas con código

El cliente necesita un código de servicio para dejar opinión, así se evita que cualquiera publique reseñas falsas.

Recorridos principales

Dos usuarios, una experiencia completa.

Para hogares

  1. Entran desde un link compartido.
  2. Filtran por zona y categoría.
  3. Comparan foto, precio y calificación.
  4. Abren el perfil completo.
  5. Contactan por WhatsApp con mensaje precargado.
  6. Luego dejan reseña usando un código válido.

Para prestadores

  1. Se registran con datos, foto de perfil y DPI.
  2. Publican precios fijos por tarea.
  3. Esperan aprobación manual del equipo.
  4. Activan su suscripción mensual.
  5. Editan precios desde su panel.
  6. Generan códigos de reseña para clientes reales.
